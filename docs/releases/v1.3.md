# 曙光 1.3｜把路线画出来，让位置动起来

**位置有了方向，路线有了自己的节奏。**

这次更新把自定义轨迹、目的地搜索和移动控制放进重新设计的原生 Android 界面，并带来全新的「日出 × 路线」应用图标。

## 这次可以怎么玩

- **跟着道路走**：选择起终点，使用百度步行 / 驾车 / 骑行推荐路线。
- **按自己的路线走**：依次放置标定点，每段按直线移动；也支持输入 BD-09 坐标。
- **直接搜目的地**：按名称或地址查找，支持城市选择和结果翻页。
- **从当前位置出发**：地图居中到系统返回的位置，可设为起点或标定点。
- **掌握移动节奏**：速度范围 `0.1–300 km/h`，支持暂停、继续、停止和实时进度。
- **离开编辑页继续行进**：移动交给原有定位服务，返回仍可控制；受系统进程与省电策略影响。

## 新界面，新图标

- 暖白与松绿的统一视觉，重新整理首页、地图、轨迹编辑、历史、设置和弹窗。
- 为地图保留更多空间，把编辑、速度与行进控制集中到底部。
- 修正侧边菜单被轨迹入口遮挡、设置摘要显示资源编号的问题。
- 新图标适配普通、圆形与 Android 自适应桌面图标。

## 下载与安装

下载下方 **`shuguang-v1.3.apk`**。不要把 GitHub 自动提供的 Source code 压缩包当作 APK。

1. Android 8.1+，安装后允许位置权限。
2. 在开发者选项中将模拟位置信息应用设为「曙光」。
3. 进入「自定义轨迹」，配置路线和速度后开始行进。

同签名版本可覆盖安装。发布包使用 Debug 签名；公开源码及 CI 产物的地图 Key 为占位符，自行构建请配置自己的 Key。当前位置读取系统提供的位置，模拟定位开启时可能返回模拟位置。
